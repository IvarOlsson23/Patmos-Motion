Overview

Easing

Three curves from one base. Standard eases in and out, Enter only eases out, Exit only eases in.

Duration

Four durations, one per pattern. Small changes are short, bigger moves are longer.

Applying motion

Every animation fits one of four patterns, based on what the element does. Each pattern sets both the curve and the duration.

Hover

State change

Curve
ease-enter
Duration
short-1 150 ms
Why
Starts at full speed, so feedback feels instant.
Used in
Button, Link, Card, Tab, Input, Select field, Search, Checkbox, List item
transition: background-color
  var(--duration-short-1)
  var(--ease-enter);

Change in place

Curve
ease-standard
Duration
medium-2 300 ms
Why
Eases in and out, so the eye can follow it from A to B.
Used in
Accordion, Toggle, Tab indicator, Input label, Notification and error space, Card arrow, Link chevron
transition: transform
  var(--duration-medium-2)
  var(--ease-standard);

Enter

Curve
ease-enter
Duration
medium-1 250 ms
Why
Arrives fast and settles softly where it lands.
Used in
Share icons, Search panel, Notification, error messages
transition: opacity, transform
  var(--duration-medium-1)
  var(--ease-enter);

Exit

Curve
ease-exit
Duration
short-2 200 ms
Why
Speeds up and leaves. Shorter than Enter, since nobody watches it go.
Used in
Cookie banner, Share icons, Search panel, Notification
transition: opacity, transform
  var(--duration-short-2)
  var(--ease-exit);

Tokens

Copy these into the codebase as CSS custom properties.

/* Patmos motion tokens */
:root {
  --ease-standard: cubic-bezier(0.75, 0.02, 0.5, 1);
  --ease-enter:    cubic-bezier(0, 0, 0.5, 1);
  --ease-exit:     cubic-bezier(0.75, 0.02, 1, 1);

  --duration-short-1: 150ms;  /* State change */
  --duration-short-2: 200ms;  /* Exit */
  --duration-medium-1: 250ms; /* Enter */
  --duration-medium-2: 300ms; /* Change in place */
  --delay-short: 50ms;       /* Delay before content fades in */
}

/* Reduced motion: stop movement, keep fades */
@media (prefers-reduced-motion: reduce) {
  .moves { transition-duration: 0ms !important; }
}

        /* Share motion: the icons fold out from behind the button */

  /* --i = 0, 1, 2 … Each icon starts at the button: one button

    transform var(--duration-short-2) var(--ease-exit),

        Page transition

        /* Page transition: Exit, then Enter */
.page {
  transition: opacity var(--duration-short-2) var(--ease-exit);
}
.page.leaving { opacity: 0; }

/* Start position of the new page (no transition) */
.page.from-up    { opacity: 0; transform: translateY(8px); }

.page.entering {
  transition:
    opacity var(--duration-medium-1) var(--ease-enter),
    transform var(--duration-medium-1) var(--ease-enter);
}

/* JS
   1. Add .leaving, wait 200 ms.
   2. Swap content. Forward: scroll to top. Back: restore scroll.
   3. Add .from-*, force a reflow, swap to .entering.
   Move focus to the new page's h1.
   Never wait for the animation if the new page is not ready:
   show it as soon as it has loaded. */

@media (prefers-reduced-motion: reduce) {
  .page.from-up { transform: none; }
}
